# Lakheni Technologies Website

## Project Title

**Lakheni Technologies Professional Business Website**

**Slogan:** *Powering Security, Connectivity, and Innovation.*

---

## 1. Project Description

This project involves the design and development of a professional website for Lakheni Technologies.

Lakheni Technologies provides security, connectivity and technology solutions for residential, commercial and organisational customers.

The website will provide information about the company's products and services and will allow potential customers to contact the business and request quotations.

The website will be developed in three stages:

* Part 1 – HTML Foundation
* Part 2 – CSS Design and Responsive Layout
* Part 3 – JavaScript Functionality and SEO

Git and GitHub will be used to manage the project and track changes throughout development.

---

## 2. Project Objectives

The main objectives of the website are to:

1. Create a professional online presence for Lakheni Technologies.
2. Provide information about the company.
3. Display the company's products and services.
4. Provide customers with convenient contact options.
5. Provide a quotation/enquiry form.
6. Create a responsive website that works on different devices.
7. Implement JavaScript functionality.
8. Improve accessibility.
9. Implement basic SEO techniques.
10. Integrate an external service such as Google Maps.
11. Use Git and GitHub for version control.
12. Maintain documentation throughout the development process.

### Mobile Navigation

A responsive mobile navigation menu was implemented using JavaScript.

The navigation menu includes a hamburger menu button that allows users to open and close the navigation links on smaller screens.

JavaScript was used to:

- Detect user interaction with the menu button.
- Add and remove the active class.
- Open and close the navigation menu.
- Update the `aria-expanded` accessibility attribute.

This improves the user experience on mobile devices and makes the website easier to navigate.
